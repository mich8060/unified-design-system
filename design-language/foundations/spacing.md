# Spacing

UDS spacing uses the `--uds-gap-*` scale: 2, 4, 8, 12, 16, 20, 24, 32, 40 px.

## Usage
- **4px** — Tight inline gaps (icon + label within a control)
- **8px** — Default control internal padding and small stack gaps
- **12–16px** — Card padding, form field vertical rhythm
- **24–32px** — Section separation within a page
- **40px+** — Major region breaks (hero to content)

In Figma, bind padding and item spacing to `uds/gap/*` layout variables—never detached px.
