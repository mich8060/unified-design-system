# Grid

Product layouts use **AppShell regions** rather than a marketing 12-column grid.

- **Menu rail** + **main column** (+ optional **listview**)
- Page content: max-width containers in docs use ~4xl–5xl; product screens often fluid within main

For dashboard grids, use CSS grid/flex with `--uds-gap-*` gutters—align cards to a consistent column rhythm.
