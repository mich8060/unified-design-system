# Sizing

Control heights and icon boxes are standardized per component (Button sizes, Input heights, Menu rail widths).

- AppShell menu expanded: **280px**; collapsed: **64px**
- Listview column: **320px** (see `ai/appshell.schema.json`)
- Icon sizes: **12, 16, 20, 24, 32** px (Phosphor `Icon` component)

Prefer component `size` props over manual width/height when a variant exists.
