# Typography

Inter is the primary UI typeface (bundled via package font export).

## Scale
Use UDS `Text` component or semantic text classes backed by tokens—not arbitrary font sizes.

Figma: apply local text styles (e.g. Body/14/Regular, Label/12/Medium) and bind fills to `--uds-text-*` semantic colors.
