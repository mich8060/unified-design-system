# Color

Colors are **semantic first**: `--uds-text-primary`, `--uds-surface-primary`, `--uds-border-primary`, status accents, brand-linked surfaces.

## Rules
- Light/dark via `.dark` class and semantic token aliases
- Brand via `brand` prop / Brand collection modes—not per-screen hex
- Emphasis through `Badge`, `Status`, `Medallion`, tinted `Card` before inventing custom accents
