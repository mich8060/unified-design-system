# Iconography

Icons are **Phosphor** glyphs via the UDS `Icon` component and package icon exports (e.g. `HouseIcon`).

## Rules
- Do not use text chevrons or custom SVG arrows when a Phosphor icon exists
- In Figma: `Icon` component with INSTANCE_SWAP—not a variant per icon
- Match icon size to control size (12–24px typical in dense UI)
