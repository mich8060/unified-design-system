# Borders

Border width token: `--uds-border-width-1` (typically 1px in production themes).

Border colors use semantic tokens: `--uds-border-primary`, `--uds-border-secondary`, `--uds-border-brand-primary`.

Use borders to separate regions—not as decoration. Prefer surface contrast and spacing when separation is sufficient.
