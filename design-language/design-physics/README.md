# Design physics

Universal principles that hold across products. They explain *why* semantics and foundations exist—not token values.

Named psychology aliases (Fitts, Hick, Jakob, Gestalt, …) resolve through the **[Laws of UX index](./laws-of-ux.md)** → these principles and linked semantics.

|-----------|------|

| Boundaries and sameness create groups | [`common-region.md`](./common-region.md) |
| Important objects gain visual weight | [`visual-weight.md`](./visual-weight.md) |
| Navigation remains spatially stable | [`spatial-stability.md`](./spatial-stability.md) |
| Motion preserves identity | [`motion-identity.md`](./motion-identity.md) |
| Contrast increases discoverability | [`contrast-discoverability.md`](./contrast-discoverability.md) |

| Interfaces consume limited mental resources | [`cognitive-load.md`](./cognitive-load.md) |
| More choices slow decisions | [`choice-complexity.md`](./choice-complexity.md) |
| Larger, closer targets are easier to hit | [`target-acquisition.md`](./target-acquisition.md) |
