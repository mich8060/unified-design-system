Create an operations queue dashboard using the Unified Design System package.

Requirements:
- import components only from `@chghealthcare/unified-design-system`
- import styles only from `@chghealthcare/unified-design-system/styles.css`
- use `AppShell` with `enableRouterOutlet={false}` and `Menu` in the `menu` slot
- put page content in `AppShell.Main`
- include `SectionHeader`, `SearchInput`, facet `Badge`s, sectioned `Item` / `ItemGroup` rows, and a `MicroCalendar` aside (from `@chghealthcare/unified-design-system/micro-calendar`)
- use `Medallion`, `Status`, and `Card` for emphasis

Before coding, read `ai/recipes/ops-queue-dashboard.md` and `ai/examples/ops-queue-dashboard.tsx`.
